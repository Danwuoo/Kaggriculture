# Runbook

> Historical V1 bounded-branch runbook. Do not use it to launch the active V2
> maximum full-tape search; current development commands are in
> `max_search/README.md`.

1. Confirm `git status -sb`; preserve unrelated and user-owned changes.
2. Run `python cli.py validate`. Any registry drift is fail-closed.
3. Build the atlas into `research/cache/full_path_topology_searcher_2026-08-17/`.
4. Use outcome-different paired traces for `forensics`; first divergence is a
   proposal window, not a causal conclusion.
5. Rank motifs independently per incumbent. Predeclare mechanism, falsifier,
   seats, families, seed freshness, and stop rule before compiling a branch.
6. Compile decompressed branch specifications only. Do not edit either
   incumbent or generated incumbent `main.py`.
7. Run technical evaluation and the lane tests. No fresh/formal games are
   authorized by this runbook.
8. Generate the development report. Proceed beyond proposal-only status only
   with separate user authorization and a fresh paired protocol.
   Before evaluation, register the complete immutable protocol/context manifest
   and candidate artifact SHA/byte/path; caller labels are rejected.

Failure handling: hash drift, schema violations, identity/private-opponent
inputs, missing compatibility fields, malformed patches, market overflow,
plant overcommit, or continuation timeout all stop or fall back; none may be
recorded as efficacy.
